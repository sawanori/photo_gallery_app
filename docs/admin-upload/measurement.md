## 実測値

### 利用者の体感（2026-08-17）

**「早くなってます」** — 実際にアップロードを行ったユーザーの報告。

これは**計測値ではなく体感である**。所要時間もリクエスト数も測っていないため、
下の表は引き続き未計測のままにしてある。改善が効いていること自体は確認できたが、
どの程度速くなったか、同時実行数をいくつにすべきかは、この報告からは決められない。

### 変更前

**未計測。** ブラウザでの操作が必要なため、この記録はまだ埋まっていない。

| 項目 | 値 |
|---|---|
| 所要時間（合計） | 未計測 |
| 1枚あたり平均 | 未計測 |
| ネットワークタブでの1枚あたりリクエスト数 | 未計測 |
| 同時実行数 | 1（直列） |

**計測手順**:

1. `cd admin && npm run dev` で管理画面を起動する
2. 上の「計測条件」の表を埋める
3. 開発者ツールを開き、ネットワークタブを記録状態にする
4. アップロードを開始し、開始から完了メッセージ表示までの時間を測る
5. ネットワークタブで `firestore.googleapis.com` と `firebasestorage.googleapis.com` へのリクエスト数を数え、枚数で割る
6. この表に記入する
